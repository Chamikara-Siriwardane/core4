# Transformer Maintenance System

**GitHub:** [https://github.com/Chamikara-Siriwardane/core4](https://github.com/Chamikara-Siriwardane/core4)  
**Project Duration:** Semester 7 Project

## Resume Description

- Developed a full-stack thermal inspection platform using Python Flask and React to digitize transformer maintenance workflows, featuring a relational database for managing baseline thermal images and environmental conditions across multiple substations.

- Engineered a computer vision-based anomaly detection system using OpenCV to automatically identify thermal deviations and hotspots by comparing maintenance images against baseline references, generating annotated visual comparisons with severity classifications and confidence metrics.

- Implemented an interactive human-in-the-loop annotation interface enabling field engineers to validate, refine, and augment AI-detected anomalies with contextual feedback, culminating in automated generation of exportable PDF maintenance record sheets for regulatory compliance and asset tracking.

---

## Technical Stack

**Backend:** Python, Flask, SQLite, OpenCV  
**Frontend:** React, JavaScript  
**Key Features:** Classical computer vision anomaly detection, interactive bounding box annotation, PDF report generation with ReportLab
